# 🌸 The Entity's Garden 🌸

> *A cozy little desktop companion for custom Dead by Daylight challenges.*

**The Entity's Garden** is a desktop application designed to make tracking custom *Dead by Daylight* challenge runs visually intuitive and organized.

✨ **Less spreadsheet energy. More gaming.** ✨

## Why Does This Exist?

This project grew from two main motivations:

### Learning Experience

I wanted to learn how to design, build, package, and distribute a desktop application with a graphical user interface.

### Community Support

The application was originally created for [LilLittleBit](https://www.twitch.tv/lillittlebit), a *Dead by Daylight* streamer whose channel I moderate for.

The goal was to create a practical tool that could make tracking her custom challenge runs smoother, easier, and significantly less chaotic.

> [!NOTE]
> This is a learning project built progressively as I learn. Because of that, optimization and code cleanup are still ongoing! Future updates are planned to improve performance and overhaul the UI framework.

## 📥 Installation

Installing the Entity's Garden is really easy!

1. Just go to the [Releases tab](https://github.com/GreenPl4nt/DBD-Challenge-Tracking-App/releases/tag/v1.1.3) or just check the latest release section on GitHub.
2. Download the installer file (`DBD.Challenge.Tracking.App.-.Installer.V1.1.3.exe`)
3. Run the Installer and just follow the instructions.
4. Launch ***DBD Challenge tracking App***
> [NOTE!]
> Currently the app is called `DBD Challenge Tracking App` which is a placeholder name, next update the name will change to `Entity's Garden`
